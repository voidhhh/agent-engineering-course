# 模块测验参考答案

开放题按机制和证据评分，不要求逐字一致。

## 模块一

1. B。模型生成候选调用，宿主执行器产生真实效果。
2. C。关键是基于观察在运行时选择下一动作。
3. 例如调用者是否有权限、目标是否属于当前租户、金额是否超限、资源状态是否允许操作。
4. 错误假设是“超时等于未执行”；实际可能已提交但响应丢失。
5. 让模型、运行时与 Trace 能把观察精确归因到请求，尤其在并行与重试时。
6. 客户端生成幂等键；服务端原子地记录键与结果；重放返回原结果；必要时提供状态查询。
7. 属于 Loop/Harness 控制；限制失控循环与成本，但不保证步骤正确、安全或任务成功。
8. 示例：“创建一个本地待办并返回 ID；仅在用户明确要求新增待办时使用。”不用于列出、修改、外部发送。
