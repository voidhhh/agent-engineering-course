# 最小 Agent Loop

让每次继续与停止都有依据

---

## 状态转移

模型返回文本 → 完成

模型返回工具调用 → 执行并回送 → 再次调用模型

越过步数预算 → 失败

---

## 必要不变量

- 工具结果绑定原调用 ID
- 每步都有预算
- Provider 错误归一化
- 历史顺序不可破坏
- 完成只由明确终止条件触发

---

## 离线测试为何关键

用 `ScriptedModel` 固定模型输出，才能单独验证 Loop，而不是把随机模型行为误判为运行时 Bug。

---

## 实验

跑通两步工具调用；再注入未知工具与无限调用，观察终态。
