# 可靠性、安全、可观测性

失败路径是一等产品路径

---

## 副作用分级

R0 只读；R1 可逆写；R2 外部影响；R3 高风险。

风险越高，身份、范围、预览和审批越强。

---

## 超时悖论

调用超时 ≠ 动作未执行。

需要幂等键、状态查询、两阶段提交或补偿。

---

## 事件链

Run → Model → Policy → Tool → State

每条事件含因果关联和受控参数摘要，敏感值不入日志。

---

## 实验

注入八类故障，检查终态、副作用次数、恢复路径与 Trace 证据。
