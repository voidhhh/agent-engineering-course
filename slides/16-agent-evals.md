# Agent Eval

从演示可用到证据可信

---

## 六个维度

结果、轨迹、安全、恢复、效率、方差。

只看最终文本会遗漏偶然猜对与越权过程。

---

## 一个 Case

输入 + 初始环境 + 允许工具 + 必要断言 + 禁止动作 + 预算 + 评分器。

---

## 控制变量

固定 Harness 比模型；固定模型比 Harness；一次消融一个能力。

高风险越权用门槛，不用平均分掩盖。

---

## 期末答辩

随机失败 Case：从 Trace 定位责任层，提出最小修复，并说明证据与限制。
