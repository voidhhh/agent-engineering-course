# Agent Eval 报告模板

## 1. 问题与假设

说明比较对象、控制变量、预期收益和可能风险。

## 2. 版本与环境

记录模型、Harness、仓库 commit、依赖、提示模板、工具 schema、随机参数、机器环境和执行日期。

## 3. 方法

说明 Case 选择、重复次数、初始状态还原、故障注入、评分器、人评盲法与安全门槛。

## 4. 结果

分别报告 F/S/R/O/E、置信区间或方差、调用数、步数、延迟与成本。附机器可读结果路径。

## 5. 失败归因

逐个高价值失败列出运行 ID、关键事件、责任层标签、最小修复和回归 Case。

## 6. 消融

一次关闭一个能力，报告收益、成本和交互效应，不把相关性写成因果。

## 7. 限制与结论

说明样本、模型波动、平台版本、评分误差与不可归因项；结论限定在实验覆盖范围内。
