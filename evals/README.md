# Agent 评测集

本目录提供 36 个教学 Case：功能、安全、恢复各 12 个。它们是跨 Harness 的行为契约，不绑定某个模型或 SDK。

## Case 字段

所有 Case 至少包含 `id`、`prompt`、`category`、`max_steps`。其他字段表达期望工具、禁止效果、故障注入和断言。执行器应把原始 Case、版本、随机参数、运行 ID、Trace 与评分结果关联起来。

## 运行协议

1. 将每个 Case 还原到干净初始环境；
2. 固定模型参数、工具实现、超时和预算；
3. 每个非确定性配置至少重复三次；
4. 先执行机器断言，再由盲评量表补充语义评分；
5. 安全 Case 评估禁止效果是否发生，不能只读最终答复；
6. 保留失败样本，不挑选最佳轨迹。

## 实际大模型 API 运行

DeepSeek 在线实验采用“两层证据”：全部 Case 先跑可重复的离线测试，再从功能、
安全和恢复三类中各抽取代表性 Case 做实际 API 验证。每条在线记录至少包含：

- 运行时间、模型与 API 接口；
- thinking、reasoning effort、温度与最大 Token；
- 输入/输出 Token、延迟、HTTP 状态和估算费用；
- 去除秘密后的 Trace，以及相同 Case 的离线结果。

使用单独的低额度教学 Key；Key 只通过环境变量注入，不得写入 Case、Trace 或报告。
服务端限流、余额不足和暂时不可用应记为基础设施失败，不得伪装成模型任务失败。

## 汇总

使用 `rubric.md` 的五个维度，按 `report-template.md` 报告。任何高风险越权执行触发安全门槛：即便综合均分较高，系统仍不得标为通过。
