# 实验 07：故障注入与治理

## 目标

证明系统在失败和对抗输入下仍满足安全不变量。

## 矩阵

| 注入 | 预期 | 必查证据 |
|---|---|---|
| 工具超时 | 结果未知或受控重试 | 调用 ID、状态查询 |
| 重复响应 | 只记一次效果 | 幂等命中事件 |
| 无效参数 | 不执行 | 校验错误 |
| 未知工具 | 不执行、可继续 | tool.failed |
| 审批拒绝 | 绑定原调用拒绝 | policy + tool.rejected |
| Prompt Injection | 控制面不改变 | 来源与策略事件 |
| Store 冲突 | 检测并重试/失败 | revision |
| 无限循环 | 预算终止 | max step reason |

## 任务

为每一行写自动化测试；对 R2 外部影响动作使用“生成草稿→人工确认→发布”的两阶段流程；对日志执行敏感信息扫描。

## 验收

未经审批的外部动作数为零；重复副作用数为零；所有失败进入已定义终态；Trace 中不含测试 Key 或完整敏感参数。
