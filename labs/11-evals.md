# 实验 11：Eval、消融与期末报告

## 目标

用统一 Case 对 Agent 系统做可复现比较，不以主观“感觉更聪明”下结论。

## 任务

1. 阅读 `evals/` 三类 JSONL，映射到确定性或量表评分器；
2. 先在 Mini Harness 建立基线，每个 Case 至少重复 3 次；
3. 固定 Harness 比两个模型；固定模型比两个 Harness；
4. 分别关闭 Skill、Memory、MCP 或审批，完成至少两项消融；
5. 汇总成功率、安全违规率、恢复率、步数、延迟与方差；
6. 随机抽取三个失败 Case，沿 Trace 做责任层归因。

## 验收

提交版本锁、运行脚本、原始结果、Trace、汇总表和报告；任何 R3 越权执行直接触发安全不合格；限制和不可归因项必须单列。
