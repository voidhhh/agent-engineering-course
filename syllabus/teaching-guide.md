# 教学实施指南

## 1. 教学方法

每个主题都采用五步法：

1. **提出失败。** 先展示一个具体失败，如工具参数幻觉或进程重启后状态丢失。
2. **画出边界。** 标出模型可见信息、宿主状态、外部系统和信任边界。
3. **重建最小机制。** 用尽可能小的代码证明抽象为何存在。
4. **观察成品。** 在 Hermes Agent、OpenClaw 或 DeepSeek Harness 中寻找同一机制。
5. **设计评测。** 将“看起来更好”转化为任务、轨迹和断言。

## 2. 课堂演示要求

- 演示前运行离线测试，确保没有 API 和网络依赖。
- 在线模型演示必须准备录制轨迹或离线 ScriptedModel 作为替代。
- DeepSeek Live Demo 使用专用低额度 Key，课前确认模型名、余额、thinking 和 Token 上限。
- 涉及写操作时先展示参数、目标和审批策略。
- 每次工具调用同时展示模型可见 schema、实际参数、执行结果和事件记录。
- 不展示真实密钥、个人文件、真实聊天记录或浏览器登录态。
- 不把 Live API 的随机失败当成 Loop 回归；先运行 Fake Client 测试定位责任层。

## 3. 原理解构模板

每讲讲义回答六个问题：

1. 这一层解决了什么问题？
2. 输入、输出和持久状态分别是什么？
3. 哪部分由模型决定，哪部分必须确定性执行？
4. 信任边界在哪里？
5. 典型失效模式是什么？
6. 用什么 Eval 才能证明改进有效？

## 4. 实验组织

实验按 Starter、Milestones、Failure Injection、Acceptance 四部分组织。学习者不得只提交最终代码，还需提交：

- 一条成功 Trace；
- 一条失败 Trace；
- 对失败机制的解释；
- 至少一个回归测试；
- 运行环境和版本记录。

## 5. 平台实验安全

Hermes Agent、OpenClaw 和 DeepSeek Harness 实验遵守以下默认设置：

- 使用专用实验目录；
- 不挂载主目录；
- 不接入真实消息渠道；
- 不暴露公网入口；
- 写操作默认审批；
- 插件和 Skill 视为受信代码，安装前审查来源；
- 实验结束删除测试密钥并清理容器。

## 6. 版本维护

每次开课前执行：

```bash
python scripts/validate_course.py
pytest
```

随后更新 `baseline-lock.md`，完成平台 smoke test，并把接口变更写入当期教学备注。讲义中的原理保持稳定，易变命令集中在实验说明中。
