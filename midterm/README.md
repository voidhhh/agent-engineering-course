# 期中项目：Inspectable Mini Harness

## 任务

在 `src/agent_course/` 基础上交付一个可检查、可暂停、可恢复的 Mini Harness。禁止用框架 Runner 完全替换核心 Loop；可以用 Provider SDK 实现 Adapter。

## 必备能力

1. 至少两个 Model Adapter，其中一个必须是确定性测试替身；
2. Tool Registry、模式校验、结构化错误与运行级幂等；
3. Session Store、revision、Checkpoint 与进程重启恢复；
4. 步数、调用数、超时和结果大小预算；
5. 允许/拒绝/需审批三态策略，审批绑定精确调用；
6. 完整状态机和 JSONL Trace；
7. 至少 18 个自动化测试，其中 8 个覆盖失败路径。

## 演示脚本

现场依次演示只读完成、写入暂停、拒绝、批准后恢复、重复调用、工具超时、进程重启恢复、无限循环终止。教师从中随机抽取四项。

## 评分（100）

| 项目 | 分值 |
|---|---:|
| Loop 与状态机正确性 | 20 |
| 工具契约与幂等 | 15 |
| Session/Checkpoint/恢复 | 20 |
| 策略与审批 | 15 |
| Trace 与可诊断性 | 10 |
| 测试与故障注入 | 15 |

未经审批执行外部影响动作、泄露密钥或无法清理测试环境，安全项不合格并需整改后重评。
