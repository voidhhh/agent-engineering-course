# 一次性课程整理 Runbook

本文件用于课程维护者在一个工作日内核验整套课程，不代表学习者应一天学完。

1. **结构检查**：运行课程验证器，确认 16 讲、16 份讲稿和 36 个 Case；
2. **离线核心**：安装开发依赖，运行测试、Ruff 和 Demo；
3. **Skill 样例**：构造一个合格和一个不合格 brief，验证脚本退出码；
4. **可选集成**：只做静态导入/语法核验；真实平台运行需独立隔离环境；
5. **资料基线**：检查规范日期、项目提交和官方安全状态；
6. **内容抽查**：每模块随机抽一讲，验证“原理—轨迹—失效—实验—验收”链路；
7. **发布检查**：确认无 Key、个人数据、运行产物和未授权许可证文本；
8. **发布后**：以 Git tag 标记课程基线，后续更新通过变更记录与回归测试进入。
